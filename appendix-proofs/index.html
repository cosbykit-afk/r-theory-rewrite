Kit's secant–cosecant identity checked proof completed numerical check

Theorem. For all real x with sin x ≠ 0 and cos x ≠ 0 (the condition sin 2x ≠ 0 is redundant):

4/sin(2x) = (tan(x) + |sec(x)| − 1/(cot(x) + |csc(x)|))
          + (cot(x) + |csc(x)| − 1/(tan(x) + |sec(x)|))

Proof. Set A = tan x + |sec x| and B = cot x + |csc x|.

Both are strictly positive on the domain: |sec x| − |tan x| = (1 − |sin x|)/|cos x| > 0 since |sin x| < 1 when cos x ≠ 0, so A ≥ |sec x| − |tan x| > 0; likewise B > 0. Hence 1/A and 1/B are defined.

Lemma. A − 1/A = 2·tan x, and B − 1/B = 2·cot x.

Proof of lemma. A² = tan² x + 2·tan x·|sec x| + |sec x|². Since |sec x|² = sec² x = 1 + tan² x,

A² − 1 = 2·tan²(x) + 2·tan(x)·|sec(x)| = 2·tan(x)·A.

Dividing by A > 0 gives (A² − 1)/A = A − 1/A = 2·tan x. ∎ The B case is identical with cot/csc.

Now regroup the right-hand side (addition commutes):

(A − 1/B) + (B − 1/A) = (A − 1/A) + (B − 1/B)
                      = 2·tan(x) + 2·cot(x)          (lemma)
                      = 2·(sin(x)/cos(x) + cos(x)/sin(x))
                      = 2/(sin(x)·cos(x))
                      = 4/sin(2x). ∎
