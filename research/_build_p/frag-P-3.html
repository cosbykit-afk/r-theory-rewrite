T1 — D₈ = ‖ZᵀZ‖²F, blind to γ checked proof

Theorem. Let Z be any real 368×556 matrix, F(Z) = Π₀ZΠ₂ + Π₂ZᵀΠ₀ (pure B↔O flip), and E_t = Π_E + F(Z). With bare B/O witnesses — and equally with the O slot dressed as O_d = Π₂ + F(γ) for any real γ:

D₈ := Tr(E_t Π₀ E_t Π₂ E_t Π₀ E_t Π₂)
   = Tr(E_t Π₀ E_t O_d E_t Π₀ E_t O_d) = ‖ZᵀZ‖²_F,

nonzero iff Z ≠ 0. The flip-O content γ drops out exactly: the dressed-O dial equals the bare-O dial.

Proof. Work in the sector-ordered block form (Π₀, Π₂, Π_rest) = (B, O, E):

E_t = [[0,  Z,  0], [Zᵀ, 0,  0], [0,  0, I_r]]
Π₀  = diag(I₀, 0, 0),   Π₂ = diag(0, I₂, 0)

Set A := E_tΠ₀E_t. E_tΠ₀ keeps the B-column of E_t; multiplying back gives a single block:

A = [[0, 0,  0], [0, ZᵀZ, 0], [0, 0, 0]]     (pure (2,2) block)

Bare-O dial: E_tΠ₀E_tΠ₂E_tΠ₀E_tΠ₂ = (AΠ₂)², and AΠ₂ = A (A is already O-sector), so Tr = Tr((ZᵀZ)²) = ‖ZᵀZ‖²F.

Dressed-O dial: with O_d = [[0, γ, 0], [γᵀ, I₂, 0], [0, 0, 0]], AO_d has only the blocks (2,0) = ZᵀZγᵀ and (2,2) = ZᵀZ. Then AO_dA has only (2,2) = (ZᵀZ)² (the (2,0)·(0,·) path vanishes since A has no (0,·) blocks), and Tr((AO_dA)O_d) = Tr((ZᵀZ)²·I₂) = ‖ZᵀZ‖²F. γ has no handle: A collapses to the (2,2) block, which sees only O_d's (2,2) = I₂. ∎

ZᵀZ is PSD, so ‖ZᵀZ‖²F = 0 ⟺ ZᵀZ = 0 ⟺ Z = 0. F(Z) is ε-odd for every real Z by the run-6 theorem (re-tripwired in run 30). Flip-only O, O_f = F(γ), gives exactly 0 (run-31 T2): AF(γ) has only the (2,0) block ZᵀZγᵀ, whose square needs (2,0)(0,2) = 0 — the Oprop flip needs the Π₂ diagonal to register in the 8-cycle at all. Removing Π_E from E_t changes nothing (run-30 T6, run-31/33 T4): the dial is a pure transfer-content functional.

T3 — D_W = 2m₀m₂·C + m₀²·D₈, sees γ checked proof

Theorem. With M_e = diag(m₀I₀, m₂I₂, M_rest) (m₀ = 2, m₂ = 5 the archived reference values, not physical selections) and O_d as above:

D_W := Tr(E_t M_e E_t O_d E_t M_e E_t O_d) = 2m₀m₂·C + m₀²·D₈,
C := Tr(ZZᵀγZᵀZγᵀ) ≥ 0.

The W4 skeleton word resolves the O-flip content γ in closed form.

Proof. B_w := E_tM_eE_t:

E_t M_e        = [[0, m₂Z, 0], [m₀Zᵀ, 0, 0], [0, 0, M_rest]]
B_w = (E_t M_e) E_t = diag(m₂ZZᵀ, m₀ZᵀZ, M_rest)

M := B_wO_d has the blocks (0,2) = m₂ZZᵀγ =: U, (2,0) = m₀ZᵀZγᵀ =: V, (2,2) = m₀ZᵀZ =: Wm:

M²(0,0) = UV       = m₀m₂ · ZZᵀγZᵀZγᵀ
M²(2,2) = VU + Wm² = m₀m₂ · ZᵀZγᵀZZᵀγ + m₀² · (ZᵀZ)²
Tr(M²) = m₀m₂[Tr(ZZᵀγZᵀZγᵀ) + Tr(ZᵀZγᵀZZᵀγ)] + m₀²Tr((ZᵀZ)²)
       = 2m₀m₂·C + m₀²·D₈      (the two cross-traces are cyclically equal)

C = Tr((ZZᵀ)(γZᵀZγᵀ)): ZZᵀ ⪰ 0 and γZᵀZγᵀ ⪰ 0 by congruence (ZᵀZ ⪰ 0); the trace of a product of two PSD matrices is ≥ 0. ∎

Cross-ratio identity checked proof

From the T3/T4 closed forms, the γ-carrying parts sit in fixed proportion:

D_W − m₀²D₈  = 2m₀m₂·C
D_B − m₀⁻²D₈ = 2(m₀m₂)⁻¹·C
(D_W − m₀²D₈)/(D_B − m₀⁻²D₈) = (m₀m₂)²       (C ≠ 0)

Bare (R = 0, i.e. γ = 0, no O-flip content): C = 0, so D_W = m₀²D₈ and D_B = m₀⁻²D₈, hence

D_W·D_B = D₈²      exactly.

Dressed (γ ≠ 0, C ≥ 0):

D_W·D_B = 4C² + 2(m₂/m₀ + m₀/m₂)·C·D₈ + D₈² ≥ D₈²,

since m₂/m₀ + m₀/m₂ ≥ 2 and every term is nonnegative. The inequality D_W·D_B ≥ D₈² is the dial test for O-flip content once the dials are measured: equality on bare witnesses, strictness signals dressed-O content (cf. the calibration's bare-vs-dressed open slot, open slot 3).

identically, for every Oprop ∈ 𝔟 and for any M_e.
