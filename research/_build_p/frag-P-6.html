P-6. Standalone theorems

Two results whose proofs stand on their own outside the book sequence: Kit's secant–cosecant identity (analytic proof plus numerical corroboration) and the Book 2 L9 nonconstancy firewall (analytic proof).

Kit's secant–cosecant identity checked proof completed numerical check

Theorem. For all real x with sin x ≠ 0 and cos x ≠ 0 (the condition sin 2x ≠ 0 is redundant):

4/sin(2x) = (tan(x) + |sec(x)| − 1/(cot(x) + |csc(x)|))
          + (cot(x) + |csc(x)| − 1/(tan(x) + |sec(x)|))

Proof. Set A = tan x + |sec x| and B = cot x + |csc x|.

Both are strictly positive on the domain: |sec x| − |tan x| = (1 − |sin x|)/|cos x| > 0 since |sin x| < 1 when cos x ≠ 0, so A ≥ |sec x| − |tan x| > 0; likewise B > 0. Hence 1/A and 1/B are defined.

Lemma. A − 1/A = 2·tan x, and B − 1/B = 2·cot x.

Proof of lemma. A² = tan² x + 2·tan x·|sec x| + |sec x|². Since |sec x|² = sec² x = 1 + tan² x,

A² − 1 = 2·tan²(x) + 2·tan(x)·|sec(x)| = 2·tan(x)·A.

Dividing by A > 0 gives (A² − 1)/A = A − 1/A = 2·tan x. ∎ The B case is identical with cot/csc.

Now regroup the right-hand side (addition commutes):

(A − 1/B) + (B − 1/A) = (A − 1/A) + (B − 1/B)
                      = 2·tan(x) + 2·cot(x)          (lemma)
                      = 2·(sin(x)/cos(x) + cos(x)/sin(x))
                      = 2/(sin(x)·cos(x))
                      = 4/sin(2x). ∎

No quadrant case split is needed: the absolute values are absorbed by |sec x|² = sec² x, so Kit's "Flatwave" Q1–Q4 argument is unnecessary for this identity (it may still be of independent interest).

Numerical corroboration: 500,000 random samples with poles excluded agree to worst |LHS − RHS| = 7.8e−07 (float rounding); near-pole residuals are pure floating-point cancellation noise, not mathematical failures.

Book 2 L9 nonconstancy (firewall) checked proof

See Book 2. Notation: urx = srx − crx, uxp = cxp − sxp (canonical sign lock); ΨU = urx + i·uxp; the complementary-swap antilinear involution T(z) = i·z̄, T² = id, with exact closure ΨU(Cx) = T(ΨU(x)) = uxp + i·urx (L1).

Theorem (L9). Symmetry closure is not differential propagation — no real scalar rate f(x) on an open primitive chart satisfies ΨU′ = f·T(ΨU).

Proof. From ΨU′ = f·T(ΨU) the components give urx′ = f·uxp, uxp′ = f·urx (urx, uxp nonvanishing), whence (urx² − uxp²)′ = 0.

But on any open quadrant, with σ₁ = sgn(sin x), σ₂ = sgn(cos x) chart-constant, the definitions give

srx = (σ₁+cos x)/sin x,   sxp = (σ₁−cos x)/sin x,
cxp = (σ₂+sin x)/cos x,   crx = (σ₂−sin x)/cos x,

whence urx − uxp = 2σ₁/sin x − 2σ₂/cos x and, with urx + uxp = 4/sin 2x (L6),

urx² − uxp² = 4(σ₁cos x − σ₂sin x)/(sin²x cos²x),

zero on each quadrant's diagonal (π/4, 3π/4, 5π/4, 7π/4, all interior) and nonzero off it (e.g. 32(√3−1)/3 at the adjacent π/6-type points). Hence urx² − uxp² is non-constant on every open primitive chart — contradiction. The T² = 1 involutive exchange and the Z₂′ = 2iZ₂ rotation are separate structures. ∎

No λ was used; the closed form was verified at all 8 octant midpoints to ~1e-14. Tripwire for any Saw→transfer argument.
