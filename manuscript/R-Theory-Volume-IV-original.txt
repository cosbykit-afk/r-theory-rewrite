17.1.1 — The harmonic carrier identity

Status: EXACT.

For x in the common domain where sin x ≠ 0 and cos x ≠ 0,

```
sin(2x)/4 = 1/(urx(x) + uxp(x))
```

where

```

```

Proof. Direct substitution using sxp = 1/srx and crx = 1/cxp, then combining over the common denominator cxp·srx − 1. ∎
